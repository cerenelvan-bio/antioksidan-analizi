# antioksidan-analizi
96 kuyucuklu plate ile antioksidan aktivite analizi - fotometrik ölçüm
## Sonuç
Kereviz ekstraktının ABTS radikaline karşı farklı konsantrasyonlardaki antioksidan potansiyeli:

- 125 µg/ml -> %65.2
- 250 µg/ml -> %68.7
- 500 µg/ml -> %72.4
- 1000 µg/ml -> %71.7

Ham plate verileri Antioksidan.xlsx dosyasında.
Yöntem: ABTS radikal süpürme aktivitesi, fotometrik ölçüm (96 kuyucuklu plate)
